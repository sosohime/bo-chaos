## 接入配置

- 前端 `GROUP_RANK_API_BASE_URL`：包括 `/group-rank` 的 HTTPS API 根路径，构建时注入。当前测试值为 `https://yuanbo.online/group-rank`；源码缺省仍为空，不调用旧产品服务。
- 服务端 `GROUP_RANK_APP_ID`、`GROUP_RANK_APP_SECRET`：对应独立小程序，由管理员在受控环境配置。
- 服务端 `GROUP_RANK_JWT_SECRET`：独立签名密钥，至少 32 字符。不放入小程序源码、构建常量、聊天或项目配置。
- 数据库沿用 Prisma，服务使用自己独立的 `group_rank_test` 数据库/账号。所选增量迁移已在该新库应用并验证备份恢复；旧 BoFans 数据库未改动。生成 Prisma 客户端不会应用迁移，也不要对独立库执行全部旧 BoFans 迁移。部署说明在 `deploy/group-rank/README.md`。

## 当前功能与限制

- 三个官方数值模板：本月跑步累计、历史引体最高、历史游戏高分。新榜绑定不可变模板快照。
- 数值范围与精度由服务端校验；排名为服务端聚合，支持并列、自己的分页历史和 revision 冲突保护。
- 删除清空成绩值，保留无成绩值的重试墓碑，避免重试恢复已删除的数据。
- 分享指向首页，可携带公开模板 ID 和无授权作用的榜单定位符；在核验当前群的榜单列表中匹配，同群直达精确活动，跨群仅推荐玩法、不请求原群详情。普通卡使用实际榜名封面，个人卡只在本人主动选择后生成名次或成绩封面；本人结果跨群不复制、不计入本群，不携带建榜规则。前台重新进入清空内存会话，普通入口不调用群登录，拒绝旧群延迟结果。
- 大厅持续提供「找之前的榜单？从群工具打开」，群内提供回访帮助；首次成功提交成绩后提示一次群工具入口，本地只存已读布尔值。群工具的具体菜单和账号能力仍需真机验收，不承诺自动添加或置顶。
- 当前已实现资料编辑、审核后的短规则、举报及私有运营队列；公开投稿、举报管理台和完整隐私账户生命周期暂不开放。

## 1.0.0 隐私声明核对（2026-11-11）

平台应选“采集”：服务保存用户主动选择的头像昵称、微信身份与群参与关系、数值记录和代填名字。用途须按真实业务声明，包括群内身份展示、保存记录、统计排行和认领；仅同群可见不代表未采集。没有手机号/定位/通讯录/聊天记录获取功能，不应为这些用途虚填声明。

真实尿酸等健康记录关联个人后涉及敏感个人信息。当前资料面板仅提示头像昵称在榜单展示，尚无专门健康信息单独同意流程；平台勾选不替代本人同意，创建者代填亦不替代本人同意。此处记录发布前需补齐的实际差距，不增加健康关键词禁用规则，也不声称已有完整账户删除/撤回机制。
