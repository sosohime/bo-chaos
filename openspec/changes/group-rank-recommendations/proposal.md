# 群内好物推荐榜

在群目录的「新建榜单」加入「好物推荐榜」。创建时填写榜名，可选填简介。沿用群目录、群分享和管理操作。

- 打开推荐弹窗时显示全部已有型号，搜索时显示所有匹配项。参与者可选已有型号，或输入新型号并推荐。型号折叠大小写、全半角和空格差异，不自动合并品牌别名或不同版本。
- 同一成员每榜最多推荐五个不同型号。重复推荐同型号只计一票。按推荐人数降序，同票并列。撤回仅影响自己的推荐，立刻释放名额。零票型号离开排名，再次被推荐时可恢复。
- 点击型号下方的头像区可见当前推荐人的头像和昵称。推荐前沿用群榜单头像昵称流程。暂停和关闭期间保留阅读和本人撤回入口。
- 群身份校验、标题和新型号内容审核在后端执行。新增两张推荐表，沿用现有榜单行锁约束并发。
