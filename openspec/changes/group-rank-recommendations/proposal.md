# 群内好物推荐榜

在群目录的「新建榜单」加入「好物推荐榜」。创建时填写榜名，可选填简介。沿用群目录、群分享和管理操作。

- 「选型号」显示已有型号、搜索匹配项及「已推荐」状态。已有和新输入型号均逐款确认，确认时可选填最多 120 字的使用感受。型号折叠大小写、全半角和空格差异，不自动合并品牌别名或不同版本。
- 同一成员每榜最多推荐五个不同型号。重复推荐同型号只计一票。按推荐人数降序，同票并列。撤回仅影响自己的推荐，立刻释放名额。零票型号离开排名，再次被推荐时可恢复。
- 点击型号下方的头像区可见当前推荐人的头像、昵称和选填感受。推荐前沿用群榜单头像昵称流程。「我的推荐」只展示本人推荐和撤回操作，暂停和关闭期间保留该入口。
- 群身份校验、标题、新型号和非空感受的内容审核在后端执行。感受随推荐保存，撤回时移除，沿用现有榜单行锁约束并发。
