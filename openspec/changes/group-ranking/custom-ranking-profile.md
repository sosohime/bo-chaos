# 自定义排行与参与资料（2026-10-30 已获用户实施授权）

- 群内：新建 → 名称必填、单位可选；默认每人最新一次、降序、不限周期 → 服务端审核通过后创建 → 进入成绩输入。
- 大厅：同一表单保存已审核玩法草稿，普通微信登录只在保存时触发；分享随机草稿 ID → 真实群入口核验 → 展示规则并明确建榜。未进入群不创建群空间。跨群只复用规则。
- 规则：latest/max/sum、asc/desc、all_time/month；规则快照不可变，数值非负、最多三位小数。latest 按提交时间（并以内部 ID 稳定同时间选择），编辑不改变提交时间。
- 内容：仅短名称与短单位，服务端 msgSecCheck=pass 才能保存；review/risky/超时/异常均不对群发布。不再按健康主题名称或单位额外拒绝；提供固定原因举报与运营处理入口。
- 头像昵称：浏览不要求资料；本人提交/修改或认领前必须完成头像与昵称；创建者代填直接填写群友名字，不触发本人资料；chooseAvatar/nickname 必须用户主动操作；服务端审核文本和重编码后的 JPEG，资料只以内部身份关联。头像请求要求本群凭证和目标用户本群参与记录；下载缓存按前台代次隔离。没有群通讯录/群昵称抓取。
- 删除：创建者移除榜单后群内不可再访问，本人和代填分数清空，保留无成绩值的幂等墓碑；举报去重，不能借举报跨群读取。
- 自定义主题（2026-11-03 用户纠正）：移除健康主题关键词黑名单；尿酸、血糖、体重等名称及 μmol/L、mmol/L、mg/dL 等单位与其他自定义排行一样，经内容审核后可以创建。仅记录与排序数值，不新增诊断阈值或医疗建议。
- 发布：增量 GroupRank schema 先备份专用测试库；冻结锁依赖、Linux Prisma 生成与新候选部署，BoFans 不切换；自动化不能替代头像选择、分享/两群真机验收。

## 创建者代填与认领（用户确认 2026-10-30）

创建者从本榜“帮群友记”选待认领名字或新增短名字并填数值。新名字经微信文本审核，生成本榜占位参与者，不伪造微信身份、不自动按同名合并、不要求未打开小程序者提供头像。创建者代填不要求本人头像昵称，不触发本人资料读写；待认领行明确标记创建者代填。

群友从真实群入口打开后，可对待认领名字申请“这是我”；申请者必须完整资料。创建者核对申请昵称，显式确认或驳回；确认提交同时携带预期申请者 ID，旧页面不得确认后来其他申请。一次确认在榜单行锁与事务内迁移原值、原始时间和代填者，接续本人现有成绩并按榜单规则重新计算。迁移后代填入口不再修改这些成绩；本人可改删，代填来源保留。不同群不可读写或认领。

最多100个同时待认领名字、每个名字500条历史（含墓碑），创建者面板返回最新100条有效记录。每人历史仍每页30条。未认领成绩的删除同样清空原值，移除榜单清空所有自填与代填值。排名读取使用一致性快照，避免认领迁移期间重复显示。
