## 当前用户旅程

1. 普通入口（搜索、下拉最近使用、普通扫码及私聊）固定打开「每群一小本」欢迎页，主入口直接发通用卡片到微信群，不要求先建榜或保存规则；也可以先设计榜单或选择公开模板。不尝试群登录，不自动恢复上次的群。
2. 客户端获取微信临时登录凭证及群入口加密载荷。
3. 服务端使用固定的独立 AppID 换取会话，在内存中解密并检查群来源；校验失败则停止，不接收客户端自报群 ID。
4. 核验通过后自动创建/复用本群空间和参与身份，无申请或审批。通用卡片和群工具打开当前群；有榜单显示目录，没有榜单显示开本页，可新建第一张榜或选择模板。群工具忽略残留参数，规则卡优先展示规则。榜单卡片定位已验证本群目录内对应的活动。目录与翻页共用服务端榜单顺序；左右翻相邻榜，上下滚动本榜排名，点页码回目录。
5. 任一参与者可以使用官方或已审核自定义规则建榜、填自己的成绩、查看排行、修改/删除自己的历史；创建者可暂停/恢复榜单。

## 群隔离与分享

- 用户身份按 `(appId, openId)` 区分；空间按 `(appId, openGid)` 区分。普通业务响应不返回原始 OpenID、群标识、session key 或群入口载荷。唯一展示例外：验证群来源后，当前会话响应必须含 displayOpenGid，客户端保留现有会话字段，但不挂载会触发平台隐私提示的 OpenData(groupName)，页头统一显示“本群”；该字段不作为读写权限参数，不读取或保存群名文字。缺字段为当前协议错误，非兼容状态。
- `POST /group-rank/session` 是群空间/成员的唯一自动创建入口；普通微信登录可仅在显式保存玩法草稿时创建独立作者身份。现有 BoFans 凭证不能用于新业务。
- 群来源必须由配置中固定 AppID 的 `jscode2session` 取得的密钥完成 AES 解密，并包含非空且长度受限的 `opengid`。兼容仅含群标识的旧版群载荷和带 `chat_type` 的新版格式；显式非 3 的聊天类型、非空单聊标识或缺少群标识均拒绝。水印不是群接口的必填字段；如果返回水印，仍严格校验其 AppID、整数时间戳、5 分钟时效与最多 30 秒未来偏差，畸形/不匹配水印不能走无水印分支。没有水印的载荷不能声称已验证其生成时间；一次性微信 code、服务端固定账号会话密钥、客户端前台重新取证明与短期本群 JWT 共同约束访问。客户端自报群 ID 始终不可信。
- 访问凭证为独立签名、issuer/audience 校验、绑定内部群空间的 15 分钟 JWT。每次受限请求还检查该业务的参与记录；所有榜单/成绩操作检查其属于当前群空间。
- 分享卡片使用首页路径，可附公开模板 ID、已审核草稿 ID 与内部榜单定位符，路径不包含群标识、成员、成绩或凭证。通用卡和规则卡使用伏案封面；榜单卡封面和标题突出当前核验榜名，排名卡封面突出本人名次；本人选择「分享我的排名」时只附本人当前名次；选择「分享我的成绩」或主动给当前榜开启右上角的成绩分享后，还附本人当前成绩及单位，不附昵称、头像、他人成绩或群名。本人结果卡不附可另建的规则，跨群打开只提示回原群，不读、导入或修改任何原群记录；已发送的图片是发送时的快照，收件人可见。普通入口保存规则后显示「发到群里」发送页，可预览卡片或返回修改；微信分享面板打开不代表发送成功。榜单定位符不授予权限：仅在服务端已核验当前群的榜单列表内匹配，同群直达精确活动，跨群不请求原榜单详情，提示该榜单不在本群，只匹配公开官方玩法或本群凭证读取已审核草稿的规则建议；没有可用规则时提示回原群。若本群已有同玩法榜单，显示实际榜名和页码；建新榜必须用户主动点击，不因打开卡片自动创建。
- 场景值 1008/1044/1158/1160 且非明确私聊类型时才请求群证明；普通入口即使有旧参数或内存令牌仍不允许访问群接口。群场景取得证明失败则展示群识别错误、重试和重新从本群群工具/卡片进入的说明，不伪装为普通大厅；不降级为 URL 授权，不出现入群申请/审批。
- 小程序每次重新进入前台会清理内存会话；旧群的延迟响应不会覆盖新群。不能据此承诺实时检测退群或完整验证微信群成员名单。

- 榜单保存不可变官方模板快照与版本。一个群可建立多个相同模板的实例。
- 时间依据服务端原始提交时间；编辑不移动统计月份。月边界是北京时间每月 1 日 00:00。
- 原始数值使用 Decimal，排名使用数据库聚合，同分采用 1、2、2、4。内部 ID 只稳定同名次的显示顺序，不打破并列。
- 没有有效成绩的人不入排名；显示经主动选择并审核的头像昵称；缺少资料时浏览回退群友代号，贡献前必须补齐。
- 成绩为用户自报，未核实竞技真实性。新建与成绩提交都带重试标识；重复请求不能悄悄变更原值。
- 修改必须提供当前 revision；冲突提示刷新。暂停/关闭后不能提交或修改，但用户仍可删除自己的成绩。

## 验证场景

- A 群空间身份请求 B 群榜单的详情、提交、修改、删除或状态变更：服务端拒绝且不访问该群成绩。
- 缺失/错误群载荷、错误会话密钥、显式私聊、其他 AppID 水印或过期水印：在写入身份和空间之前拒绝；无水印但有合法解密群标识的群载荷可进入。
- 只有普通客户端登录成功、没有群证明：不能获取本群数据。
- 老产品 cookie/JWT 或缺少 Bearer：不能进入受限接口；提交额外 `spaceId` 会被验证层拒绝。
- 修改过期 revision、重复请求更换成绩、重放已删除请求：冲突，不覆盖或恢复记录。
- 月份在北京时间午夜变化、精确小数相等、同分排名跳号：结果符合上述规则。
- 旧群响应迟于新入口返回：客户端丢弃旧结果，不以旧会话读取新群。
